# Roadmap

## Introducción

El desarrollo del proyecto seguirá un enfoque incremental.

Cada fase deberá construir las capacidades necesarias para la siguiente.

No se desarrollarán componentes que dependan de infraestructura todavía inexistente.

---

# Fase 1 - Infraestructura

Objetivo

Construir la infraestructura mínima necesaria.

Incluye:

- estructura del proyecto;
- configuración común;
- sistema de logging;
- bibliotecas comunes.

Resultado esperado

Disponer de una base estable sobre la que desarrollar el resto del sistema.

---

# Fase 2 - Sistema base

Objetivo

Preparar un sistema Linux listo para instalar herramientas de desarrollo.

Incluye:

- actualización del sistema;
- utilidades básicas;
- herramientas de red;
- compiladores;
- utilidades comunes.

---

# Fase 3 - Lenguajes

Objetivo

Instalar los lenguajes necesarios para el desarrollo.

Incluye:

- Java;
- Python;
- R;
- Node.js.

---

# Fase 4 - Herramientas

Objetivo

Instalar las herramientas principales del entorno.

Incluye:

- Git;
- Docker;
- Quarto;
- TinyTeX;
- RStudio;
- DBeaver.

---

# Fase 5 - IA

Objetivo

Preparar el entorno de ingeniería asistida por IA.

Incluye:

- OpenSpec;
- Ollama;
- modelos;
- herramientas auxiliares.

---

# Fase 6 - Automatización

Objetivo

Construir procesos completos utilizando los módulos desarrollados.

Incluye:

- instalación completa;
- instalación parcial;
- verificación global;
- actualización.

---

# Fase 7 - Documentación

Objetivo

Documentar completamente el sistema.

Incluye:

- laboratorio;
- manual técnico;
- ADR;
- documentación de usuario.

---

# Criterios de avance

Una fase únicamente podrá darse por finalizada cuando:

- todos sus módulos funcionen correctamente;
- las verificaciones sean satisfactorias;
- la documentación correspondiente esté actualizada.

---

# Evolución

El roadmap constituye una guía.

Podrá modificarse cuando aparezcan nuevos requisitos o cambien las prioridades del proyecto.

No obstante, deberá respetarse siempre el principio de construir primero la infraestructura sobre la que se apoyarán las siguientes fases.
