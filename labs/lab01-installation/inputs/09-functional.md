# Requerimientos Funcionales

## RF-001

El sistema deberá permitir instalar un componente de forma individual.

---

## RF-002

El sistema deberá permitir ejecutar una instalación completa.

---

## RF-003

El sistema deberá verificar cada instalación realizada.

---

## RF-004

El sistema deberá detectar componentes previamente instalados.

---

## RF-005

El sistema deberá registrar todas las operaciones realizadas.

---

## RF-006

El sistema deberá permitir actualizar componentes.

---

## RF-007

El sistema deberá informar de errores de instalación.

---

## RF-008

El sistema deberá permitir seleccionar módulos concretos.

---

## RF-009

El sistema deberá mostrar las versiones instaladas.

---

## RF-010

El sistema deberá generar un informe final del proceso.
